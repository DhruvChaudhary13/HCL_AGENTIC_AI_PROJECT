# Dataset folder

Put the training CSV here. For the default setup this is `diabetic_data.csv` from the
UCI "Diabetes 130-US Hospitals for Years 1999-2008" dataset:

https://archive.ics.uci.edu/dataset/296/diabetes-130-us-hospitals-for-years-1999-2008

The notebook tries to download it automatically; if that fails, download the zip
manually, unzip it, and copy `diabetic_data.csv` into this folder.
